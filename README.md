# Rule extraction from feedforward neural networks: literature database

The papers and methods reviewed in

> S. El Mekkaoui, L. Benabbou, A. Berrado. *Rule-Extraction Methods From Feedforward Neural Networks: A Systematic Literature Review.* arXiv:2312.12878, 2023. <https://arxiv.org/abs/2312.12878>

**Browse the database: <https://saraelmekkaoui.github.io/rule_ext_ann/>**. You can filter by the review's taxonomy, search, view the timeline, copy BibTeX, and export a selection.

The database covers 89 papers describing 81 rule extraction methods for feedforward neural networks in supervised learning, published from 1988 to 2021. Each method is classified along the dimensions of the review:

| Dimension | Values |
|---|---|
| Approach | Explore & test, Induced models, Attribution, Optimization, Hybrid |
| Translucency | Pedagogical, Decompositional, Eclectic |
| Design | Post-hoc, Intrinsic |
| Application | Model-agnostic, Model-specific |
| Scope | Global, Local |

Definitions are in Section 2 and Table 2 of the paper.

## Downloads

- [`rule-extraction-papers.bib`](docs/downloads/rule-extraction-papers.bib): BibTeX for all 89 papers.
- [`rule-extraction-methods.csv`](docs/downloads/rule-extraction-methods.csv): one row per method, with its classification and papers.

## How to cite

If you use this database, please cite the paper above:

```bibtex
@article{elmekkaoui2023rule,
  title   = {Rule-Extraction Methods From Feedforward Neural Networks: A Systematic Literature Review},
  author  = {El Mekkaoui, Sara and Benabbou, Loubna and Berrado, Abdelaziz},
  journal = {arXiv preprint arXiv:2312.12878},
  year    = {2023}
}
```

## Repository layout

```
data/papers.bib      one entry per paper (source of truth)
data/methods.csv     one row per method: id, name, papers, approach, translucency, design,
                     application, scope, technique (source of truth)
scripts/build.py     validates data/ and generates docs/data, docs/downloads and the tables below
docs/                the website (GitHub Pages)
```

To change the database, edit the two files in `data/`, then run `python scripts/build.py` (Python 3.9+, no dependencies) and commit the regenerated files. `python scripts/build.py --check` validates the data and fails if generated files are out of date; GitHub runs it on every push.

This repository is a record of the published review and does not accept paper submissions.
